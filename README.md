## 👨‍💻 About Me

I am a PhD-trained Applied AI Engineer and Data Scientist working at the interface of **machine learning, scientific computing, optimisation, computer vision, and analytical software development**.

My work focuses on turning complex experimental and industrial datasets into useful models, visualizations, decision-support tools, and reusable Python workflows.

I enjoy building practical systems that go beyond notebooks: from data cleaning and exploratory analysis to feature engineering, modelling, evaluation, automation, visualization, and deployable prototypes.
