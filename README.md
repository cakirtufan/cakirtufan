### 👨‍💻 About Me

I work on **data science, machine learning, and analytical software**, with a strong focus on scientific and industrial data.

My main interest is building practical tools around complex data workflows: from data cleaning and exploratory analysis to feature engineering, modeling, evaluation, visualization, and decision-support systems.

I enjoy working at the interface of **physics, data analysis, machine learning, and software development**.
